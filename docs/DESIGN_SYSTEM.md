# Визуальная философия FORMA TELA

## Идея

«Много форм. Один покой». Интерфейс передаёт спокойствие, внимание к телу и ощущение натуральных материалов. Клиенту показывается простая запись, администратору — функциональное рабочее пространство с ясной иерархией.

## Цвета

| Токен | Значение | Смысл и применение |
|---|---|---|
| green | `#284B35` | Жизнь, тело, природа. Основные действия, активные состояния и навигация. |
| sand | `#D8C6A6` | Земля и материальный мир. Тёплые поверхности и мягкие разделители. |
| paper | `#F8F5EE` | Тишина и пространство. Основной фон. |
| gold | `#BE9D52` | Осознанность. Редкий небольшой акцент, например ожидающая заявка или несохранённая точка. |

Текущие CSS custom properties определены в `dist/style.css`. Палитра настраивается через DemoAPI. Новые яркие цвета без функциональной причины не вводить.

## Типографика и композиция

- Спокойные заголовки с засечками сочетаются с нейтральным sans-serif текстом интерфейса.
- Важность показывается размером, ритмом и размещением. Не утяжелять всё жирным начертанием.
- Использовать открытые поля и свободные промежутки. Карточки и поля ограничивать по ширине там, где растяжение мешает чтению.
- Границы тонкие, радиусы умеренные. Избегать тяжёлых теней и крупных цветных плашек.
- Админка компактна по содержимому: небольшие кнопки и поля на desktop, области нажатия около 44 px на touch-устройствах.

## Движение

Переходы плавные, короткие и ненавязчивые. Не использовать резкие прыжки, вращения и тяжёлый blur. Учитывать `prefers-reduced-motion`. Focus Mode мягко выделяет выбранную публичную секцию и сбрасывается при намеренной ручной прокрутке.

## Адаптивность

Широкий desktop использует боковое меню и многоколоночные формы. На планшетах календарь и панели перестраиваются в одну колонку, публичная форма записи становится двухколоночной. На телефонах интерфейс вертикальный, меню и фильтры можно прокручивать по горизонтали, поля и действия удобны для касания. Контент не должен требовать горизонтального скролла страницы. Проверять ширины 320, 375, 768, 1024 и 1440 px.

## SVG и фирменная графика

Исходные SVG лежат в `dist/assets/brand/`:

- `Breath-of-Unity.svg` — анимированная заставка.
- `logos/logo-01.svg` … `logo-06.svg` — фирменные символы для шапки, услуг, разделов и статусов.

Предпочитать именно эти SVG-версии; сохранять их векторными и не заменять PNG при отображении логотипов. Для интерфейсных пиктограмм использовать единый лёгкий контурный вес. SVG логотипов не редактировать без отдельного дизайн-запроса.
